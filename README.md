# AI 学习智能体 · 人工智能通识课

下一代 AI 学习方案的前端原型：**左边是课程，右边是陪你学的学习助手**。

- 课程内容来自《第一讲：人工智能发展史与基础概念》（王一博）。
- 页面设计来自 [设计稿](https://claude.ai/artifact/D2kGfMNyKs9YwuTJpU2HMQ)。

## 运行

纯静态页面，没有构建步骤：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。直接双击 `index.html` 也可以打开。

## 页面

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `#/plan` | 开课诊断与学习方案 | 助手问 3 个问题加学习节奏，实时生成个性化路线：为你加强 / 快速通过 |
| `#/learn/1.2` | 学习页 | 左侧是课程目录和正文，右侧是助手：本节目标、对话、随堂检测 |
| `#/check/2` | 掌握检测 | 拖拽分类（或排序）。答错时助手不直接给答案，而是苏格拉底式追问，并在课程里插入对比图；之后“换个说法”再确认一次 |
| `#/profile` | 学习档案 | 知识地图（23 个知识点的掌握度）、讨论题观点、方案、演示模式 |

## “学习智能体”的行为

- **个性化路线**：根据诊断结果，把补充块插进对应小节，或把已掌握的小节标成“快速通过”。
- **改写课程**：点“换个讲法”或提问，助手把比方或对比卡片直接插进正文，并提供“已插入课程 ↗”的定位链接。
- **陪伴式反馈**：互动组件会把关键时刻告诉助手，助手会主动点评。例如：XOR 训练失败、强化学习收敛、情感分析被反讽骗到。
- **掌握才解锁**：每节都有随堂检测，每章都有掌握检测，通过后才解锁后续内容。为了方便审阅，目前默认全部解锁；在“学习档案”里关掉“演示模式”，就会恢复按进度解锁。
- **选中即问**：在正文里选中一段文字，就可以直接问助手。

## 内容形式：按难度选，学习效率优先

不是每个知识点都需要互动。难度决定花多少时间，内容本身决定用什么形式：

| 难度 | 形式 | 什么时候用 |
| --- | --- | --- |
| 基础 | 图文 | 是什么、是谁、哪一年。读一读、看张图就懂，最快 |
| 中等 | 视频片段（1 分钟左右） | 要看到过程才懂：一步步发生、起起落落、信号怎么流动 |
| 难点 | 视频或图文 + 实验 | 要亲手改参数、看结果才真正懂，而且实验做的是真实计算，不是事先写好的动画 |

视频片段取自 `../video/ai_intro` 的 HTML 讲解动画，按场景切出，必要时只取其中几句旁白。片段带字幕和可点击的文字稿，播完后助手会接着引导；有视频的小节，要等视频看完才自动出随堂检测。

**第 4 章是试点**：4.1（难点）视频 + 实验，4.2（中等）视频，4.3、4.4（基础）只用图文。其余章节还是原来的做法。

修改或新增视频片段：编辑 `tools/sync_video.py` 里的 `CLIPS`，然后运行

```bash
python3 tools/sync_video.py
```

它会从 `../video/ai_intro` 复制舞台文件（需要先在那边生成好 `build/narration.wav`），切出每个片段的音频，并生成 `assets/video/clips.js`。

## 结构

```
index.html
assets/css/app.css          设计令牌与全部样式
assets/js/core.js           状态（localStorage）、事件、图标、动画工具
assets/js/course.js         课程内容：章、节、内容块、检测、助手脚本、补充块
assets/js/widgets/ch1-5.js  各章互动组件
assets/js/assistant.js      右侧助手：消息流、打字效果、随堂检测卡片、选中即问
assets/js/pages.js          开课方案 / 学习页 / 掌握检测 / 学习档案
assets/js/app.js            路由与启动
assets/img/                 讲义里的原图（课程正文用）
assets/video/clips.js       视频片段的起止时间和文字稿（由 tools/sync_video.py 生成）
assets/video/ai_intro/      讲解动画的 HTML 舞台（从 ../video 同步）；player.html 是片段播放器
assets/video/lib/           动画引擎（从 ../video 同步）
tools/sync_video.py         同步视频舞台、切片段音频
```

助手的回答目前由课程脚本和关键词匹配驱动。接入真实大模型时，替换 `pages.js` 里的 `respond()` 即可。
